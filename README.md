# schedule

大学生が自分の時間割・予定・課題を1つで見るために作った、個人用のカレンダーとタスク管理。

`index.html` をブラウザで開けば動く。ビルド工程も外部ライブラリも無い。

---

## できること

**カレンダー**

- 今日ビュー … 上から読むだけのリスト。次いつ・どこ、このあとの予定、今日やるタスク
- 週ビュー … 0時から24時までの時間軸。予定は実際の長さで表示される
- 月ビュー … 全体をざっと見る用
- 授業は毎週くり返す予定として1件だけ登録する
- 日をまたぐ予定は、上の帯に横長のバーで出る

**狭い画面では今日ビュー、広い画面では週ビューが既定**になる。3つとも常に選べる。

ナビゲーションは、大型PCでは左サイドバー、小型PC・タブレットでは上部、スマートフォンでは下部へ切り替わる。

**タスク**

- 期限切れ / 今日・明日 / 今週 / それ以降 に分かれて並ぶ
- 丸を押すと完了。完了したものは畳まれる
- 「今日やる」に数件だけ上げられる。翌日には自動で外れる

**種類（カテゴリ）**

- 授業・バイト・サークルのように分けて、色を付けられる
- 色・名前・並び順は設定から変えられる

**設定**

- 独立した設定画面で、同期の状態、テーマ、表示する時間帯、時限、種類、データの書き出し／読み込みを管理

**保存先**

- Googleカレンダー。どの端末からでも同じ予定が見える
- スマホの標準カレンダーアプリにも同じ予定が出る

## 使いはじめる

公開とGoogleカレンダー連携は設定済み。手順は `SETUP.md` に残してある。

**コードを触らずに変えられるもの**（アプリの「設定」から）

- テーマ（紙／夜）
- 表示する時間帯
- 時限（1限〜6限の時刻）
- 種類（カテゴリ）の色と名前

**コードを触る必要があるもの**（`index.html` の上のほう）

| | |
|---|---|
| `HOUR_PX` | 週ビューの1時間ぶんの高さ |
| `DAY_HOUR_PX` | 今日ビューの1時間ぶんの高さ |
| `CONFIG.taskCalendarId` | タスクだけ別のカレンダーに分けたいとき |

## 手を入れるとき

```bash
node test.js
```

65件のテストが走る。**1件でも落ちたら直してから出すこと。**
目で見て気づきにくいところ（日付のズレ、予定の重なり、Googleとの相互変換、
参照している要素の欠落、文字の大きさ、テーマごとの読みやすさ）を検査している。

画面ごと動かして確かめたいときは、任意で `smoke.js` が使える。

```bash
npm install jsdom
node smoke.js
```

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | アプリ本体。これ1つで動く |
| `AGENTS.md` | 書き方の決まりごと。**手を入れる前に読む** |
| `STATUS.md` | いまの状態と、これまでに決めた設計方針 |
| `SETUP.md` | 公開・アプリ化・Googleカレンダー連携の手順 |
| `test.js` | 検証用 |
| `smoke.js` | 画面ごと動かして確かめる補助（任意） |
| `manifest.json` / `icon-*.png` | ホーム画面やデスクトップに入れるための設定 |

## AIに手伝ってもらうとき

このリポジトリはAIに編集させることを前提に整えてある。

- **`AGENTS.md`** … 守ってほしい決まりごと。Codex や Cursor は自動で読む
- **`CLAUDE.md`** … Claude Code 用（中身は `AGENTS.md` と同じ）
- **`STATUS.md`** … いまどこまで進んでいて、何を決めたか。**理由まで書いてある**

チャット型のAIに貼るときは `AGENTS.md` → `STATUS.md` → `index.html` の順。
頼み方の例は `STATUS.md` の末尾にある。
